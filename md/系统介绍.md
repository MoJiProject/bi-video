# 青芒视频

青芒视频是一个面向视频内容与创作者社区的在线视频平台。用户可以发现和观看视频、发送弹幕、发表评论，也可以发布作品和动态，与其他用户交流分享。

## 产品特色

- **观看与互动一体化：** 视频播放结合弹幕、评论、点赞、收藏、分享和观看记录。
- **内容与社区并重：** 除视频外，还支持图文动态、关注关系、个人空间和站内私信。
- **创作者工具：** 提供视频投稿、稿件管理、内容审核及创作数据查看。
- **共同观看：** 用户可创建一起看房间，与其他参与者同步播放和交流。
- **多端适配：** 页面支持桌面、平板和手机浏览器，布局随屏幕尺寸调整。
- **统一视觉风格：** 以青绿色为主色，采用清晰、轻量的卡片式界面。

## 主要功能

### 视频与内容发现

- 首页推荐、分区浏览和关键词搜索
- 视频播放、播放进度记录和相关推荐
- 实时弹幕、评论、点赞、收藏与分享
- 稍后观看及观看历史管理

### 用户与社区

- 注册登录、个人资料和隐私设置
- 个人空间、关注与粉丝列表
- 图文动态发布、评论、点赞和分享
- 私信会话与站内通知

### 创作与平台管理

- 视频投稿、稿件编辑和状态管理
- 视频审核、评论与动态管理
- 用户管理、搜索热词、首页横幅及操作记录

### 一起看

- 创建或加入观看房间
- 同步播放、暂停、进度和倍速
- 房间成员与管理操作

## 技术栈

| 层级 | 技术 |
|---|---|
| Web 前端 | Vue 3、Vue Router、Pinia、Element Plus、Axios |
| 服务端 | Java 21、Spring Boot 3.3、Spring MVC、WebSocket |
| 数据访问 | MyBatis、MyBatis-Plus |
| 数据与缓存 | MySQL、Redis |
| Web 服务与代理 | Nginx |

## 运行环境

- **浏览器：** 支持现代桌面和移动浏览器；不支持 Internet Explorer 11。
- **前端开发：** Node.js 与 npm，用于安装前端依赖和运行开发服务。
- **后端运行：** Java 21 运行环境。
- **数据服务：** MySQL 和 Redis。
- **部署方式：** 前端静态资源可由 Nginx 提供；Nginx 可将 API 与 WebSocket 请求转发至后端应用。
- **默认端口：** 后端应用 `8081`；Nginx 常用 `80/443`。数据库和 Redis 端口由部署配置决定。

本项目面向本地开发、功能演示和自有环境部署。生产环境请根据实际业务配置数据库、缓存、媒体存储、域名及 HTTPS。
