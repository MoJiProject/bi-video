bi-video
===

界面主题、图标、文案均为本项目自有设计与实现（主题色 `#0FA68E` 青玉 / `#FF8A4C` 蜜橙，
图标为自绘 SVG 后批量导出的 PNG），未使用任何第三方站点的品牌素材。

## 主题与素材
- 主色：`#0FA68E`（青玉），点缀色 `#FF8A4C`（蜜橙），等级/会员高亮 `#F0A03C`（琥珀）
- 色板集中在 `static/src/assets/css/global.css` 的 `:root` CSS 变量里，
  Element Plus 的 `--el-color-primary` 及其 light-3/5/7/8/9、dark-2 全套都指向这套变量
- 站点图标放在 `static/public/img`，文件名不再包含任何第三方品牌字样
  （`logo.png` 横向文字标、`logo-banner.png` 登录页标、`favicon.ico`、等级徽章、互动操作图标等）

## 个人空间接口

`/home` 页面使用 `product-app`，请求统一通过 `services/http.js` 发送，登录凭证放在
`token` 请求头，不再使用旧版加密载荷或 `Authorization` 认证。
`/api/home/*` 提供投稿、动态、图文、收藏夹及收藏视频查询，分页返回
`records`、`total`；视频和动态分别使用 `VideoListItemVO`、`PostVO` 字段。
主页资料、签名和隐私设置使用 `/api/auth`，关注操作使用 `/api/user`，
关注及粉丝列表使用 `/api/home/relations`。
访问权限由后端根据登录身份判断，不使用前端传入的浏览者 ID 授权。

当前隐私设置支持收藏、关注列表、粉丝列表；投币记录、点赞记录和生日仅本人可见。
尚未提供代表作配置和追剧接口，对应入口不会展示模拟数据或调用旧版地址。

## 响应式布局

首页保留桌面多列、平板双列和手机单列视频流，分类导航支持横向滚动。
视频卡片的稍后观看按钮在触屏和键盘聚焦时可见，不依赖鼠标悬停。
首页、搜索、动态及个人空间外层共用 `--page-max`、`--page-pad`，不单独收窄动态页；
动态正文保留阅读限宽，图片网格、附件选择和作者信息随可用宽度收缩、换行。
个人空间在窄屏将导航、搜索和统计分行展示；动态、投稿和站内搜索的侧栏切换为
横向筛选，收藏网格按容器宽度排列，分页与长文本允许换行，不隐藏功能入口。

## Banner管理

后台列表入口为 `/systemManagement/banner`，支持新增、编辑、删除、排序和隐藏。
图片必填，支持JPG/PNG/GIF，最大10MB；内容选填，填写内容时链接必填。
链接支持HTTP/HTTPS或以 `/` 开头的站内路径。首页按排序升序、ID倒序最多展示6张，
每5秒自动轮播并支持手动切换，内容叠加在图片内部底部，有链接的图片可点击跳转。

本分支使用首页现有的首屏Banner区域，保留其尺寸和响应式占位，不引入旧分支510×370px的固定布局；
未配置展示项时保留现有首页。接口通过 `services/http.js` 和 `token` 请求头访问，
管理端身份以服务端登录用户为准，不接收客户端提供的管理员ID，写操作记录到 `operation_log`。
图片复用当前上传存储及 `/upload/` 静态资源服务。

已有 `product` 数据库执行 `sql/product/04_banner.sql`；新建数据库的 `01_schema.sql` 已包含该表。
不要对已有数据库重新执行全量建表脚本。

## 接口与上传部署

页面统一使用 `services/http.js` 和 `token` 请求头。历史及稍后观看使用
`/api/history/list`、`/api/watch-later/list`，游标为记录 ID，不是视频 ID；
动态使用 `/api/post`，账号编辑使用 `/api/auth/account`。

已有数据库需执行 `sql/product/03_post_like.sql`，新增动态点赞关系表。
新建数据库使用更新后的 `01_schema.sql`，无需重复建表。
上传统一使用 `/api/media/{category}`，图片支持 PNG/JPEG/GIF（10MB），
视频支持 MP4/WebM/Ogg（500MB）。通过 `app.upload-dir` 配置持久化目录，
默认路径为相对于后端工作目录的 `../static/public/upload`。
开发代理和 Nginx 都将 `/upload/` 转发到后端；Nginx 的 `/api/` 转发保留前缀。
